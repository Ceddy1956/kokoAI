# kokoAI

The **Ember & Moss Sanctuary** application code, procedural 2D artwork, Web Audio synthesizer, and the **Koko** character are dedicated to the public domain under **CC0 1.0 Universal** (see `LICENSE`).

Major Updates

GoEmotions Integration – Added an emotion recognition system based on the GoEmotions dataset.

Context-Aware Emotion Detection – Improved emotion analysis to recognize phrases, negations, intensifiers, contrasting statements, and mixed emotions.

Expanded Conversation Database – Integrated four conversational datasets:

ESConv

EmpatheticDialogues

DailyDialog

GoEmotions

Improved Emotional Support – Expanded the conversational foundation for more empathetic and supportive responses.

Personality Modes – Added distinct conversational personalities: Wise, Empathetic, Socratic, and Warm.

Active Listening Modes – Added Listen, Untangle, and Advice modes.

Support Preferences – Added Listen, Comfort, Reflect, and Distract preferences.

Comfort Letters – Added 15 built-in Reasons to Stay letters.

Cozy Jokes – Added 13 built-in jokes to make conversations lighter.

Technical Improvements

Added a weighted emotion-scoring system.

Improved emotion classification using contextual cues.

Added support for identifying multiple emotions in a single message.

Expanded the internal conversation database.

Improved the chatbot's ability to interpret emotional expressions.




### Third-Party Academic Datasets
This project includes locally embedded retrieval examples from the following research datasets, which remain subject to their respective academic licenses:
* **ESConv (Emotional Support Conversation):** Liu et al. (2021), *"Towards Emotional Support Dialog Systems"*, ACL. Licensed under [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/).
* **EmpatheticDialogues:** Rashkin et al. (2019), *"Towards Empathetic Open-domain Conversation Models"*, ACL.
* **DailyDialog:** Li et al. (2017), *"DailyDialog: A Manually Labelled Multi-turn Dialogue Dataset"*, IJCNLP
